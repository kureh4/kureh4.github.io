# 打ち込みフォーム（iPhone / Android PWA）
公開先（GitHub Pages設定が有効な場合）: https://kureh4.github.io/entry-form/

5項目：席名、名前、写真指名、ドリンク、ショット。
「次へ」「戻る」、未入力時の赤枠エラー、プレビュー、コピーしてLINEのトーク一覧へ移動。

## インストール
- iPhone: Safariで公開URLを開き、共有 → ホーム画面に追加。
- Android: Chromeで公開URLを開き、︙ → アプリをインストール／ホーム画面に追加。

## プライバシー
入力内容を外部サーバーには送信せず、ページ内でだけ処理します。コピー成功後、フォーム内の入力は消去します。クリップボード上の内容はOSが管理します。

## 制約
LINE通常グループの個別トークへの直接移動や送信自動化は行いません。LINEの公式トークタブURL (`https://line.me/R/nv/chat`) を開きます。端末によってOSの確認画面が表示されたり、手動で「LINEを開く」をタップする必要があります。ブラウザの権限でコピーできない場合には、プレビュー文章の手動コピーを案内します。

Scriptable版とは独立したWebアプリです。
